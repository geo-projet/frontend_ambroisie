1. Pourquoi ce tableau de bord ?

Ce tableau de bord est un outil en ligne gratuit qui permet de visualiser et d'analyser la présence de l'ambroisie (herbe à poux) sur le territoire des trois villes du projet : Sherbrooke, Montréal et Québec.

Un guide pour trois cartes. Les captures d'écran de ce guide viennent de Sherbrooke, la première ville livrée. Les trois cartes partagent le même fonctionnement, mais chaque ville ne propose que les couches que publie sa municipalité : le panneau Informations de chaque carte en dresse la liste.

C'est un outil essentiel pour faciliter la prise de décision en matière d'éradication de cette espèce allergène.

8. Cas d'usage concrets

Découvrez comment utiliser le tableau de bord à travers des situations réelles.

Cas 1 – Citoyen allergique : évaluer le risque autour de son domicile

Objectif : Connaître le niveau de risque d'allergie près de chez soi

Étape Action: 1- Cliquer sur l'icône Analyses 2- Aller dans l'onglet « Autour de moi » 3- Choisir le rayon 250 m (ajustez selon vos besoins) 4- Saisir son adresse complète (numéro, rue, ville, code postal) 5- Lire le nombre d'observations dans la zone 6- Consulter le graphique d'évolution annuelle pour voir la tendance
Décision possible : S'il y a beaucoup d'observations, fermer les fenêtres pendant la période de pollinisation (août-septembre), ou signaler des pieds d'ambroisie dans son quartier sur iNaturalist.

Cas 2 – Gestionnaire municipal : prioriser un arrondissement/secteur pour l'arrachage

Objectif : Identifier le secteur le plus touché pour optimiser les interventions

Étape Action: 1- Cliquer sur Analyses → onglet « Répartition » 2- Sélectionner « Par secteur » dans la liste déroulante 3- Identifier le secteur avec la barre la plus haute du graphique 4- Activer la couche « Secteur » (icône ) pour visualiser les limites 5- Utiliser Zoom secteur pour aller directement dans ce secteur 6- Planifier les équipes d'arrachage sur ce secteur prioritaire
Décision possible : Concentrer les ressources financières et humaines sur l'arrondissement le plus touché pour maximiser l'impact des actions d'éradication.

Cas 3 – Chercheur / étudiant : analyser le lien entre type de sol et présence d'ambroisie

Objectif : Comprendre les facteurs environnementaux favorisant l'ambroisie

Étape Action: 1- Activer la couche « Types de sols » (icône ) 2- Cliquer sur Analyses → onglet « Répartition » 3- Sélectionner « Par type de sol » dans la liste déroulante 4- Identifier les sols avec le plus d'observations (barres les plus hautes) 5- Sur la carte, observer les zones correspondant à ces types de sols 6- Comparer avec les secteurs urbanisés (couche Affectation des sols)
Découverte possible : L'ambroisie se développe davantage dans les sols sableux et les milieux anthropisés (bords de routes, friches, zones urbaines).

Cas 4 – École / sensibilisation : montrer l'évolution temporelle

Objectif : Sensibiliser sur les périodes à risque et l'évolution dans le temps

Étape Action: 1- Cliquer sur Analyses → onglet « Évolution » 2- Montrer le graphique mensuel : expliquer le pic en août-septembre (période de pollinisation) 3- Montrer le graphique annuel : expliquer la tendance (hausse ou baisse selon les années) 4- Basculer sur la carte avec la couche « Observations » activée 5- Zoomer sur différents arrondissements pour comparer les densités 6- Discuter des actions de prévention possibles (arrachage, tonte, sensibilisation)
Message clé : La période août-septembre est critique pour les personnes allergiques. Les actions d'arrachage sont plus efficaces avant la floraison (mai-juin).
